# Offline map data

`natural-earth-countries-110m-v5.1.2.geojson` is the Natural Earth 1:110m Admin 0
dataset. It is public domain and pinned to
[`natural-earth-vector` v5.1.2](https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2/geojson).
LocalFi serves it from `/maps/` so Travel works offline.

See the [terms of use](https://www.naturalearthdata.com/about/terms-of-use/).
