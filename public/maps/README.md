# Offline map data

`natural-earth-countries-110m-v5.1.2.geojson` is the Natural Earth 1:110m
Admin 0 countries dataset from the version-pinned
[`natural-earth-vector` v5.1.2 release](https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2/geojson).
It is served by LocalFi from `/maps/` so the Travel globe does not require a
browser-time network request.

Natural Earth data is in the public domain. See the upstream
[Natural Earth terms of use](https://www.naturalearthdata.com/about/terms-of-use/).

`6866c877d39cba9c357620878839b336d569f8c662d3cfab4cb1dbe2d39c977f`.
